## Theme findings

### Visual hierarchy

Live HUD is WorldExploration’s top strip. GameFlow pins Items / Board / Feats / Bosses at `z-9001`. Chat starts unfolded (`defaultFolded={false}`) at `z-9000` (`UX-CHAT-DEFAULT-OPEN`). Zone Tier n is always on and its dialog is a generic HTML `<dialog>` (`UX-ZONE-LOCK-SAAS-CHROME`). Small-screen Continue is the same generic `#aaaaaa` / serif card (`UX-SMALL-SCREEN-SAAS-CHROME`). Boss Rush chip is still `#FF69B4`. Summon-control AP/MP orbs still use Tailwind blue/green. Rename uses a `#141726` card. Canvas crash recovery is a full-screen monospace dump (`UX-CANVAS-ERROR-DUMP`).

### Action discoverability

After Play, GameFlow unmounts the select/forge header (`UX-NO-LEAVE-REALM`). First map still has no coach. Chat + Map Effects start open over that first map. Battle Boost is still unmounted. Items vs Buy Doka still collide. Portal labels are still dungeon-only on main. Empty battle-bar slots still say only “Empty slot N”. Dungeon-chain shrine rooms have no chrome. Map # never says it is visit count, not difficulty (`UX-MAP-NUMBER-WHY`). Profile submit still says “Enter the Realm” (`UX-PROFILE-REALM-CTA`). Piece picker never says look-only (`UX-FORGE-PIECE-COSMETIC`). Boss Guide scaling is an unlabeled level-10 example (`UX-BOSS-GUIDE-ASSUMED-LEVEL`).

### Feedback / invalid actions

Cast/walk rejects still often live in the battle log. Login with a missing canister ID still fails silently; post-auth is “Loading...” (`UX-AUTH-LOADING-VOID`). Portal +10 XP still has no “securing” whisper. Flee still uses native `window.confirm` (dungeon/rush adds a second confirm — already `UX-FLEE-NATIVE-CONFIRM`). Lava death still waits 1.5s with HP already restored. Shrine +300 Doka has no toast. A sealed dungeon/rush exit only `logBattleEntry`s (`UX-SEALED-PORTAL-LOG-ONLY`). Spellbook Cancel looks like undo after an immediate Upgrade spend (`UX-SPELLBOOK-CANCEL-KEEPS-UPGRADES`).

### AP / MP / spell / enemy / hazards

Battle orbs still print current AP/MP without `/ max`. Side-panel jewels already print `n/max`. Inspect chips print SP / SR / RES / CHC / FAIL with no titles (`UX-INSPECT-STAT-WORDS`); inspect FAIL is hardcoded `0` while Statistics uses live `spellFailChance` (`UX-FAIL-INSPECT-ZERO`). Hazard tiles never name themselves before the step. Summon lifespan is still pips only. HUD leftover XP is unlabeled (`UX-HUD-XP-LEFTOVER-LABEL`). During a controlled summon, the champion spell bar stays enabled under a second full-bleed control strip (`UX-SUMMON-BAR-OVERLAP`). Empty catalog still blames an admin (`UX-SPELLBOOK-EMPTY-ADMIN`).

### Portals / rewards / death / HUD / modals / responsive

Dungeon labels nearby; rest / boss / colored / white / Death Realm exits do not. Combat death vs lava death still two UIs. Recap has no LEVEL UP chrome. `<768px` Continue anyway. Chat posts as the profile name while the HUD shows the champion. HP potion buy cards never say battle-turn (`UX-POTION-CARD-BATTLE-ONLY`); elixir/boots already do.
