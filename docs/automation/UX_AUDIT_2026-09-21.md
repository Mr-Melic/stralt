## Theme findings

### Visual hierarchy

Live HUD is WorldExploration’s top strip (name, level, Map #, leftover XP, region, Doka, cart). GameFlow pins Items / Board / Feats / Bosses under a spacer at `z-9001`. Challenge panel is `z-index: 1200`, so the tool cluster can paint over it on a crowded tablet (`UX-HUD-TOOL-CLUSTER`, `UX-CHALLENGE-ZINDEX`).

Boss Rush room chip is still `#FF69B4` arcade pink (`UX-BOSS-RUSH-PINK`). Not restyled this run — `WorldExploration.tsx` is already in older open PRs.

Identity drift (`UX-IDENTITY-FONT-DRIFT`): DESIGN.md asks for Space Grotesk / Inter / OKLCH. Live CSS is Baloo 2 / Saira; `index.html` title is still “Paper Baby Vampires”. Next new screen only. No repo-wide hex sweep.

### Action discoverability

First map still has no coach (`UX-ONBOARD-FIRST-MAP`). Champion forge now shows starting vitals **and** a 20-character name hint. Overworld spells stay muted until `inBattle`.

Buy Doka after GameKey is email → Mollie → admin approval → 120-char redeem. How-to steps and email-before-QR are on main. HUD cart is still icon-only next to an Items button that also uses `ShoppingCart` (`UX-SHOP-TWO-STORES`). Not labeled this run (WX overlap).

Challenge offer is **in-battle**, until the first action. This run adds “Accept before you move or cast” plus a Skip bonus door.

### Feedback / invalid actions

Cast failures on the canvas often spawn float text. Walk “Can't reach” / “Not enough MP” and summon-control rejects still go to the battle log (`UX-CAST-FAIL-FEEDBACK`). Players who never open chat get no reason.

GameKey paste whitespace is stripped this run (`UX-GAMEKEY-PASTE-WHITESPACE`).

### AP / MP / spell / enemy

Battle orbs show current AP/MP plus a 30px mini bar, not `current / max` numerals (`UX-AP-MP-CURRENT-MAX`). Side-panel jewels still use `vitalsOrbCaps`. Enemy inspect lives on initiative chips; Enemies register is labeled flavor lore.

### Portals / rewards / death / HUD / modals / responsive

Dungeon portals label when nearby; rest / boss / colored / white sanctuary / Death Realm exits do not (`UX-PORTAL-LEGEND`). When `dungeonChainActive`, the nearby-label branch is `p.color === "dungeon" || dungeonChainActive`, so **non-dungeon** portals can inherit “Continue Chain” copy. Recap leftover XP is truthful. Combat death still unmounts into Game Over; lava death still fires the root recap and auto-enters the realm in 1.5s (`UX-DEATH-DUAL-MODAL`). `<768px` offers Continue anyway (`UX-SMALL-SCREEN-HARD-BLOCK`). Changelog still appears only after II re-login (`UX-VERSION-FORCE-RELOGIN`). `APP_VERSION` remains `v163` — this run did not bump it.
