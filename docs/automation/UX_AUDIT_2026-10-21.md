## Theme findings

### Visual hierarchy

Live HUD is WorldExploration’s top strip. GameFlow pins Items / Board / Feats / Bosses at `z-9001`. Zone Tier n is always on at bottom-right (`currentZoneTier` starts at 1) and its dialog is a generic HTML `<dialog>` with `#aaa` body copy and pill ON/OFF — not carved stone (`UX-ZONE-LOCK-SAAS-CHROME`). Boss Rush chip is still `#FF69B4`. Summon-control AP/MP orbs still use Tailwind blue/green. Rename uses a `#141726` card (`UX-RENAME-SAAS-CHROME`). World feat toast still prints `+N Doka` on main.

### Action discoverability

After Play, GameFlow unmounts the select/forge header (`UX-NO-LEAVE-REALM`). First map still has no coach. Battle Boost is still unmounted. Items vs Buy Doka still collide; the Items modal’s first tab is still **Shop**. Portal labels are still dungeon-only on main (`nearbyPortalLabel` locked in #776). Empty battle-bar slots still say only “Empty slot N” (`UX-EMPTY-BAR-EQUIP`; copy locked this run). Dungeon-chain shrine rooms have no chip, no altar draw, and no hover (`UX-SHRINE-INVISIBLE`).

### Feedback / invalid actions

Cast/walk rejects still often live in the battle log. Login with a missing canister ID still fails silently. Portal +10 XP still has no “securing” whisper. Flee still uses native `window.confirm`. Lava death still waits 1.5s with HP already restored. Shrine +300 Doka has no toast; a 3-map covenant is written and never read (`UX-COVENANT-DEAD-BUFF`).

### AP / MP / spell / enemy / hazards

Battle orbs still print current AP/MP without `/ max`. Side-panel jewels already print `n/max`. Initiative chips are the inspect surface. Hazard tiles never name themselves before the step. Summon lifespan is still pips only. Initiative phase chrome stays YOUR/ENEMY while the battle bar can say Summon's Turn and YOUR TURN at once.

### Portals / rewards / death / HUD / modals / responsive

Dungeon labels nearby; rest / boss / colored / white / Death Realm exits do not. Combat death vs lava death still two UIs. Recap has no LEVEL UP chrome. `<768px` Continue anyway. Chat posts as the profile name while the HUD shows the champion. Recap still prints +Doka on claim-gated feats.
