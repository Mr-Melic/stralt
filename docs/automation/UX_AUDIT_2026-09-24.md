## Theme findings

### Visual hierarchy

Live HUD is WorldExploration’s top strip (name, level, Map #, leftover XP, region, Doka, cart). GameFlow pins Items / Board / Feats / Bosses under a spacer at `z-9001`. Challenge panel is `z-index: 1200`, so the tool cluster can paint over it on a crowded tablet (`UX-HUD-TOOL-CLUSTER`, `UX-CHALLENGE-ZINDEX`).

Boss Rush room chip is still `#FF69B4` arcade pink (`UX-BOSS-RUSH-PINK`, WorldExploration ~17586). Not restyled — `WorldExploration.tsx` is already in older open PRs.

Identity drift (`UX-IDENTITY-FONT-DRIFT`): DESIGN.md asks for Space Grotesk / Inter / OKLCH. Live CSS is Baloo 2 / Saira (`index.css` `--font-display`). Next new screen only. No repo-wide hex sweep.

Selection heading still shouts “Paper Baby Vampire” on main (`UX-SELECTION-PBV-HEADING` queued in #421). GameFlow’s select/forge wordmark and the browser tab still say Paper Baby Vampires (`UX-LAUNCH-TAB-TITLE`).

Quiet maps used to keep a **Map Modifiers** panel that only said “No active modifiers,” stacked with Battle Boost’s own empty “Map Effects” list. This run hides the map-effects overlay until a modifier actually rolls (`UX-MAP-MODIFIERS-EMPTY`). Boost still owns a duplicate empty subsection (`UX-BOOST-MAP-EFFECTS-DUP`).

### Action discoverability

First map still has no coach (`UX-ONBOARD-FIRST-MAP`). Champion forge already shows starting vitals on main. Overworld spells stay muted until `inBattle`.

Buy Doka after GameKey is email → Mollie → admin approval → 120-char redeem. HUD cart is still icon-only next to an Items button that also uses `ShoppingCart` (`UX-SHOP-TWO-STORES`). GameKey how-to steps are already wired on main (`IAP_SHOP_STEPS`).

Challenge offer is **in-battle**, until the first action. Accept-window / Skip-bonus copy is still #372.

Battle Boost asks the player to pick **XP Boost** or **Rewards** (+50% Doka) and then locks that choice for the fight, but never says the pick is exclusive, that it applies to the next persist, or that “Rewards” means Doka (`UX-BOOST-MODE-TEACHING`).

Realm tools label the leaderboard **Board** (`UX-BOARD-LABEL`).

### Feedback / invalid actions

Cast failures on the canvas often spawn float text. Walk “Can't reach” / “Not enough MP” still go to the battle log (`UX-CAST-FAIL-FEEDBACK`). Changelog overlay on main still uses SaaS “please review before playing” (#464 rewrites that).

### AP / MP / spell / enemy

Battle orbs show current AP/MP plus a 30px mini bar, not `current / max` numerals (`UX-AP-MP-CURRENT-MAX`, BattleUIPanel ~412). Side-panel jewels still use `vitalsOrbCaps`. Enemy inspect lives on initiative chips; AP/MP in that slide-out can print `?`, and SP / CHC have no glossary (`UX-STAT-ABBREV-GLOSSARY`). Enemies register is labeled flavor lore.

### Portals / rewards / death / HUD / modals / responsive

Dungeon portals label when nearby; rest / boss / colored / white sanctuary / Death Realm exits do not (`UX-PORTAL-LEGEND`, WorldExploration ~7916). When `dungeonChainActive`, the nearby-label branch is `p.color === "dungeon" || dungeonChainActive`, so **non-dungeon** portals can inherit “Continue Chain” copy. Recap leftover XP is truthful. Combat death still unmounts into Game Over; lava death still fires the root recap and auto-enters the realm in 1.5s (`UX-DEATH-DUAL-MODAL`). Recap still has no LEVEL UP chrome (`UX-LEVEL-UP-CHROME`). `<768px` offers Continue anyway (`UX-SMALL-SCREEN-HARD-BLOCK`). Changelog still appears only after II re-login (`UX-VERSION-FORCE-RELOGIN`). `APP_VERSION` remains `v163`.
