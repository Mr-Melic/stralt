## Theme findings

### Visual hierarchy

Live HUD is WorldExploration’s top strip (name, level, Map #, leftover XP, region, Doka, cart). GameFlow keeps a pointer-events-none spacer plus an Items / Board / Feats / Bosses cluster at `z-9001`. Mid-width tablets still collide (`UX-HUD-TOOL-CLUSTER`).

Boss Rush room chip is still `#FF69B4` arcade pink (`UX-BOSS-RUSH-PINK`). Dungeon depth uses carved crimson. Leftover-XP fill stays Dofus purple.

Summon control orbs use Tailwind `blue-500` / `green-500` (`UX-SUMMON-SAAS-ORBS`) while DESIGN.md asks for OKLCH primary/success jewels. Do not “fix” that with shadcn cards.

Identity drift (`UX-IDENTITY-FONT-DRIFT`): DESIGN.md asks for Space Grotesk / Inter / OKLCH. Launch title measures serif/Arial; `index.css` is Baloo 2 / Saira. Next new screen only.

### Action discoverability

First map still has no coach (`UX-ONBOARD-FIRST-MAP`).

**New this run:** `BoostToggle.tsx` is never imported. App holds `boostMode` and passes it to GameFlow, which discards it (`_boostMode` / `_onBoostToggle`). WorldExploration keeps a private `boostMode` stuck on `"xp"` (`_setBoostMode` unused). Victory always applies the +50% XP multiplier; the Doka +50% path cannot be chosen (`UX-BOOST-UNMOUNTED`). Teaching copy on the unmounted panel (`UX-BOOST-MODE-TEACHING`) is blocked until a human mounts it.

Cart next to the Doka chip is icon-only (`title`/`aria` “Buy Doka”) vs the Items tool (`UX-SHOP-TWO-STORES`). Board vs Leaderboard (`UX-BOARD-LABEL`). Feats vs Achievements (`UX-FEATS-VS-ACHIEVEMENTS`, owned by #354).

### Feedback / invalid actions

Cast failures still go to canvas floats / the battle log (`UX-CAST-FAIL-FEEDBACK`). Flee uses a native `window.confirm` (`UX-FLEE-NATIVE-CONFIRM`) — copy names Death Realm, chrome is OS-generic. Login only banners when `login()` throws (`UX-LOGIN-SILENT-BACKEND`).

Overworld heal **label** uses the affordable slice (`Heal N HP → C Doka (1:3)`); the **hover title** still quotes a full-heal price (`UX-HEAL-TITLE-MISMATCH`). Helper `overworldHealButtonCopy` is ready; WorldExploration is owned by older PRs so it is not wired this run.

### AP / MP / spell / enemy

Battle orbs still print `N AP` / `N MP` plus a 30px bar (`UX-AP-MP-CURRENT-MAX`). The 30s timer has no “turn auto-ends” legend (`UX-TURN-TIMER-WHY`). Initiative inspect still uses `extraStats.ap ?? "?"` and raw SP/CHC (`UX-STAT-ABBREV-GLOSSARY`). Side-panel Statistics rows have no `title` glossary either. Enemy Register is labeled flavor lore on main.

### Portals / rewards / death / HUD / modals / responsive

Dungeon labels when nearby; other kinds do not (`UX-PORTAL-LEGEND`). Recap leftover XP is truthful. Combat death still unmounts into Game Over; lava death still fires the root recap and auto-enters the realm in 1.5s (`UX-DEATH-DUAL-MODAL`). `<768px` offers Continue; no stacked HUD (`UX-SMALL-SCREEN-HARD-BLOCK`). Changelog still appears only after II (`UX-VERSION-FORCE-RELOGIN`). `APP_VERSION` was not bumped (still `v163`).
