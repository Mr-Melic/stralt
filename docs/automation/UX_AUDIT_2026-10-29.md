## Theme findings

Zone Tier n is always on and its dialog is a generic HTML `<dialog>`. Small-screen Continue is the same generic `#aaaaaa` / serif card and cites a raw 768px breakpoint. Boss Rush chip is still `#FF69B4`. Summon-control AP/MP orbs still use Tailwind blue/green. Canvas crash recovery is a full-screen monospace dump. Side panel repeats the leftover XP bar. Boss encounter banner is a 1.5s purple gradient. Map Effects chrome title disagrees with the inner “Map Modifiers” header. Region fallback is the literal word Unknown. Chat Status groups live effects as **ENEMY E-3** (`UX-CHAT-STATUS-ENEMY-ID`).

After Play, GameFlow unmounts the select/forge header. First map still has no coach. Chat + Map Effects start open over that first map. Battle Boost is still unmounted. Slot cards print raw `\u2694`. Death Realm / Rest Area HUD chips never name the next step. Landing ads are image-only. Rest Area never says it does not heal. Spellbook summon chips expose `hpScale` formulas on hover. Map entry still announces **hazard tiles detected** (`UX-HAZARD-COUNT-DETECTED`, helper locked this run). Empty maps still log **No map modifier this area** (`UX-NO-MODIFIER-LOG`).

Victory recap CTA never names dungeon / rush / overworld. DoT ticks dump `[DOT] target=…`.
