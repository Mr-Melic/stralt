## Theme findings

### Visual hierarchy

Live HUD is WorldExploration’s top strip. GameFlow pins Items / Board / Feats / Bosses at `z-9001`. Chat starts unfolded (`defaultFolded={false}`) at `z-9000` (`UX-CHAT-DEFAULT-OPEN`). Zone Tier n is always on and its dialog is a generic HTML `<dialog>` (`UX-ZONE-LOCK-SAAS-CHROME`). Small-screen Continue is the same generic `#aaaaaa` / serif card (`UX-SMALL-SCREEN-SAAS-CHROME`). Boss Rush chip is still `#FF69B4`. Summon-control AP/MP orbs still use Tailwind blue/green. Rename uses a `#141726` card. Canvas crash recovery is a full-screen monospace dump (`UX-CANVAS-ERROR-DUMP`). Jackpot heal hit is casino 🎰 / serif gold (`UX-HEAL-JACKPOT-UNNAMED`). Side panel repeats the leftover XP bar under the live HUD bar (`UX-SIDE-PANEL-XP-REDUNDANT`). Boss encounter banner is a 1.5s purple gradient (`UX-BOSS-BANNER-FLASH`). Map Effects chrome title disagrees with the inner “Map Modifiers” header (`UX-MAP-EFFECTS-DUAL-LABEL`).

### Action discoverability

After Play, GameFlow unmounts the select/forge header (`UX-NO-LEAVE-REALM`). First map still has no coach. Chat + Map Effects start open over that first map (#517 will unmount empty Map Effects). Battle Boost is still unmounted. Items vs Buy Doka still collide. Portal labels are still dungeon-only on main. Empty battle-bar slots still say only “Empty slot N”. Dungeon-chain shrine rooms have no chrome. Map # never says it is visit count, not difficulty (`UX-MAP-NUMBER-WHY`). Profile submit still says “Enter the Realm” (`UX-PROFILE-REALM-CTA`) and claims the account name is on the Board (`UX-PROFILE-BOARD-NAME-MISLEAD`). Piece picker never says look-only (`UX-FORGE-PIECE-COSMETIC`). Boss Guide scaling is an unlabeled level-10 example (`UX-BOSS-GUIDE-ASSUMED-LEVEL`). Slot cards print raw `\u2694` (`UX-SELECT-SLOT-LITERAL-ESCAPE`). Initiative portraits print raw `\uD83D\uDC51` (`UX-INIT-STRIP-LITERAL-ESCAPE`). Death Realm / Rest Area HUD chips never name the next step (`UX-DEATH-REALM-NEXT-CHIP`, `UX-REST-AREA-NEXT-CHIP`). Side-panel `(x, y)` never says Tile (`UX-TILE-COORD-HUD`). Landing ads are image-only (`UX-LANDING-ADS-UNLABELED`). Rest Area never says it does not heal (`UX-REST-AREA-NO-HEAL`).

### Feedback / invalid actions

Cast/walk rejects still often live in the battle log. Login with a missing canister ID still fails silently; post-auth is “Loading...” (`UX-AUTH-LOADING-VOID`). Portal +10 XP still has no “securing” whisper. Flee still uses native `window.confirm` (dungeon/rush adds a second confirm — already `UX-FLEE-NATIVE-CONFIRM`) and says “20% XP” (`UX-DEATH-XP-LEFTOVER-COPY`). Lava death still waits 1.5s with HP already restored. Shrine +300 Doka has no toast. A sealed dungeon/rush exit only `logBattleEntry`s (`UX-SEALED-PORTAL-LOG-ONLY`). Spellbook Cancel looks like undo after an immediate Upgrade spend (`UX-SPELLBOOK-CANCEL-KEEPS-UPGRADES`). Pack fights have no banner (`UX-ENCOUNTER-NO-BANNER`). Attack Nearest disabled hover is one generic sentence (`UX-ATTACK-NEAREST-WHY`). Heal button ends `(1:3)` (`UX-HEAL-RATIO-CRYPTIC`). Battle phase column prints `T{n}` (`UX-TURN-INDEX-T-PREFIX`). Ground Doka collect prefixes `[COLLECT]` (`UX-GROUND-DOKA-LOG-ONLY`). Victory recap CTA never names dungeon / rush / overworld (`UX-RECAP-CONTINUE-VOID`).

### AP / MP / spell / enemy / hazards

Battle orbs still print current AP/MP without `/ max`. Side-panel jewels already print `n/max` but look spendable on the overworld (`UX-OVERWORLD-AP-MP-IDLE`). Inspect chips print SP / SR / RES / CHC / FAIL with no titles (`UX-INSPECT-STAT-WORDS`); inspect FAIL is hardcoded `0` while Statistics uses live `spellFailChance` (`UX-FAIL-INSPECT-ZERO`); player summons inspect as Enemy (`UX-INSPECT-SUMMON-AS-ENEMY`). Hazard tiles never name themselves before the step. Summon lifespan is still pips only; summon bar name is raw `pieceType` (`UX-SUMMON-NAME-PIECETYPE`). HUD leftover XP is unlabeled (`UX-HUD-XP-LEFTOVER-LABEL`). During a controlled summon, the champion spell bar stays enabled under a second full-bleed control strip (`UX-SUMMON-BAR-OVERLAP`). Empty catalog still blames an admin (`UX-SPELLBOOK-EMPTY-ADMIN`). Champion slots do not grey on AP (`UX-SPELL-AP-DISABLED-REASON`). Persisted ATK / resilience / evasion never appear on the player HUD (`UX-HUD-DEAD-ATK-EVA`). Spell hover uses `CD: 2t` (`UX-SPELL-CD-TURNS`). Status pills use `{n}t` (`UX-STATUS-TURNS-SUFFIX`). Physical slots stamp `PHY` (`UX-SPELL-PHY-LABEL`). Striker offer still says Chebyshev (`UX-CHALLENGE-CHEBYSHEV`).

### Portals / rewards / death / HUD / modals / responsive

Dungeon labels nearby; rest / boss / colored / white / Death Realm exits do not. Boss Rush next-room portal is log-only (`UX-BOSS-RUSH-ADVANCE-LABEL`). Transition chip is `Portal...` (`UX-PORTAL-TRANSITION-OPAQUE`). Combat death vs lava death still two UIs. Recap has no LEVEL UP chrome. `<768px` Continue anyway. Chat posts as the profile name while the HUD shows the champion. HP potion buy cards never say battle-turn (`UX-POTION-CARD-BATTLE-ONLY`); elixir/boots already do. Summon spellbook lists 10× and gates on that list while `upgradeSpell` charges the usual rank-up (`UX-SUMMON-UPGRADE-COST-GATE`). Board table still has an “Achievements” column under a Feats button (`UX-FEATS-VS-ACHIEVEMENTS`). Dungeon HUD never names the live Doka ×N (`UX-DUNGEON-CHAIN-MULTIPLIER`). Legendary challenges advertise a Badge that is not persisted (`UX-CHALLENGE-BADGE-VOID`).
