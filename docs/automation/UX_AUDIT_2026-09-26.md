## Theme findings

### Visual hierarchy

Live HUD is WorldExploration’s top strip. GameFlow pins Items / Board / Feats / Bosses at `z-9001`. Challenge panel is `z-index: 1200`. Boss Rush chip is still `#FF69B4`. Summon-control AP/MP orbs still use Tailwind blue/green (`UX-SUMMON-SAAS-ORBS`). This run retitles the folded Settings dock to **Sound** so it reads as a jewel-adjacent SFX control, not a SaaS gear menu.

### Action discoverability

**New P1:** after Play, GameFlow unmounts the select/forge header. `showBackButton` is false for `world`. There is no Champions / Log Out in the realm tool cluster (`UX-NO-LEAVE-REALM`). Log Out still exists on the pre-world header only.

First map still has no coach. Battle Boost is still unmounted (`UX-BOOST-UNMOUNTED`). Items vs Buy Doka still collide. Enemies register is flavor lore (honesty banner on main).

### Feedback / invalid actions

Cast/walk rejects still often live in the battle log. Login with a missing canister ID still fails silently (`UX-LOGIN-SILENT-BACKEND`). Portal +10 XP still must not touch the HUD until `applyRewards` commits — and there is still no “securing +10 XP” whisper (`UX-PORTAL-XP-PENDING`).

### AP / MP / spell / enemy / hazards

Battle orbs still print current AP/MP without `/ max`. Initiative chips are the inspect surface; SP/SR/CHC have no glossary. Hazard tiles draw lava/ice/spike pixels but hover only shows battle-walk MP cost — never “lava burns” before the step (`UX-HAZARD-TILE-LEGEND`). Summon lifespan is pips + hourglass, no “fades in N turns” (`UX-SUMMON-LIFESPAN-WORDS`).

### Portals / rewards / death / HUD / modals / responsive

Dungeon labels nearby; rest / boss / colored / white / Death Realm exits do not. Combat death vs lava death still two UIs. Recap has no LEVEL UP chrome. `<768px` Continue anyway. Chat posts as the **profile** name while the HUD shows the **champion** (`UX-CHAT-PROFILE-NAME`). Flee still uses `window.confirm`.
