## Theme findings

### Visual hierarchy

Live HUD is WorldExploration’s top strip. GameFlow pins Items / Board / Feats / Bosses at `z-9001`. Chat starts unfolded (`defaultFolded={false}`) at `z-9000`. Zone Tier n is always on and its dialog is a generic HTML `<dialog>`. Small-screen Continue is the same generic `#aaaaaa` / serif card and now also cites a raw **768px** breakpoint (`UX-SMALL-SCREEN-PX`). Boss Rush chip is still `#FF69B4`. Summon-control AP/MP orbs still use Tailwind blue/green. Canvas crash recovery is a full-screen monospace dump. Side panel repeats the leftover XP bar. Boss encounter banner is a 1.5s purple gradient. Map Effects chrome title disagrees with the inner “Map Modifiers” header. Region fallback is the literal word **Unknown** (`UX-ZONE-UNKNOWN-LABEL`).

### Action discoverability

After Play, GameFlow unmounts the select/forge header. First map still has no coach. Chat + Map Effects start open over that first map. Battle Boost is still unmounted. Items vs Buy Doka still collide. Portal labels are still dungeon-only on main. Empty battle-bar slots still say only “Empty slot N”. Dungeon-chain shrine rooms have no chrome. Map # never says it is visit count. Profile submit still says “Enter the Realm”. Piece picker never says look-only. Boss Guide scaling is an unlabeled level-10 example whose column is **ΔLvl** (`UX-BOSS-GUIDE-DELTA`). Slot cards print raw `\u2694`. Death Realm / Rest Area HUD chips never name the next step. Landing ads are image-only. Rest Area never says it does not heal. Spellbook summon chips expose `hpScale` formulas on hover (`UX-SUMMON-SCALE-TOOLTIP`).

### Feedback / invalid actions

Cast/walk rejects still often live in the battle log. Login with a missing canister ID still fails silently. Portal +10 XP still has no “securing” whisper. Flee still uses native `window.confirm`. Lava death still waits 1.5s with HP already restored. Shrine +300 Doka has no toast. A sealed dungeon/rush exit only `logBattleEntry`s. Spellbook Cancel looks like undo after an immediate Upgrade spend. Pack fights have no banner. Attack Nearest disabled hover is one generic sentence. Heal button ends `(1:3)`. Battle phase column prints `T{n}`. Ground Doka collect prefixes `[COLLECT]`. Victory recap CTA never names dungeon / rush / overworld. **DoT ticks dump `[DOT] target=…` (`UX-DOT-LOG-ENGINEER`).** **Non-DoT ticks log “expired” while the buff still has turns (`UX-EFFECT-EXPIRED-FALSE`).** **`playerTakesDamage` always writes “Player took N…” then the caller writes a second cast line (`UX-PLAYER-DMG-DOUBLE-LOG`).** **Ice uses a reject ❌ and says Slowed while applying Frozen −2 MP (`UX-ICE-SLOW-MISLABEL`).** **Barrier fade interpolates the `"x,y"` map key (`UX-BARRIER-COORD-LOG`).** **Forge failure toasts the raw `Error.message` (`UX-CREATE-SAVE-RAW-ERR`).**

### AP / MP / spell / enemy / hazards

Battle orbs still print current AP/MP without `/ max`. Side-panel jewels already print `n/max` but look spendable on the overworld. Inspect chips print SP / SR / RES / CHC / FAIL with no titles; inspect FAIL is hardcoded `0`; player summons inspect as Enemy. **Inspect ACTIVE EFFECTS reads `turnOrder[].activeEffects`, which combat never fills — HUD pills are live, inspect says none (`UX-INSPECT-EFFECTS-EMPTY`).** Hazard tiles never name themselves before the step. Summon lifespan is still pips only; summon bar name is raw `pieceType`. HUD leftover XP is unlabeled. During a controlled summon, the champion spell bar stays enabled. Empty catalog still blames an admin. Champion slots do not grey on AP. Persisted ATK / resilience / evasion never appear on the player HUD. Spell hover uses `CD: 2t`. Status pills use `{n}t`. Physical slots stamp `PHY`. Striker offer still says Chebyshev. **Hit and enemy-cast logs name chess `pieceType` (`UX-HIT-LOG-PIECETYPE`).** **`spellEngine` appends `base → scaled → sp +N% → sr × res → final` (`UX-DMG-BREAKDOWN-JARGON`).** **Fetid Rook lore recommends “RES gear” in a game with no gear (`UX-ENEMY-REGISTER-GEAR`).**

### Portals / rewards / death / HUD / modals / responsive

Dungeon labels nearby; rest / boss / colored / white / Death Realm exits do not. Boss Rush next-room portal is log-only. Transition chip is `Portal...`. Combat death vs lava death still two UIs. Recap has no LEVEL UP chrome. `<768px` Continue anyway. Chat posts as the profile name while the HUD shows the champion. HP potion buy cards never say battle-turn. Summon spellbook lists 10× and gates on that list while `upgradeSpell` charges the usual rank-up. Board table still has an “Achievements” column under a Feats button. Dungeon HUD never names the live Doka ×N. Legendary challenges advertise a Badge that is not persisted. Buy Doka status line says **hinted** and **Admin credits** (`UX-GAMEKEY-ADMIN-HINT`).
